# YouTube Downloader

YouTube の音声・動画を保存する、Windows 用アプリです。起動時は **Music Download** タブが開きます。

**[最新版をダウンロード](https://github.com/sakuya121212/youtube-downloader/releases/latest)**

## 利用に必要なもの

- Windows 10／11 の64bit（x64）PC
- YouTube に接続できるインターネット環境
- アプリ本体・音声・変換中の一時ファイルを保存できる空き容量
- ユーザーフォルダーと音声保存先への書き込み権限

**Python・Node.js・FFmpeg の追加インストールや、管理者権限は不要です。**

## はじめ方

ダウンロードページの「Assets」から、次のどちらかを選んでください。

| 種類 | 起動方法 |
|---|---|
| インストーラー版（`-setup.exe`） | ダウンロードしたファイルを実行してインストールし、スタートメニューから起動します。 |
| ZIP 版（`-windows-x64.zip`） | ZIP をすべて展開し、中の `YouTubeDownloader.exe` を起動します。 |

ZIP 版は、**exe と `_internal` フォルダーを一緒に保持**してください。exe だけを移動すると正常に動きません。
「Source code」は開発用です。通常の利用には上記の配布ファイルを選んでください。

## 音声を保存する

**Music Download** タブを使用します。

1. 保存したい動画の URL を貼り付けます。
2. 必要に応じて保存先・保存形式・音質を変更します。ファイル名は「詳細設定を開く」から変更できます。
3. **Download** を押し、完了を待ちます。

初期設定では、Windows の「ダウンロード」フォルダーに **MP3／320 kbps** で保存します。
設定は次回の起動時にも引き継がれます。

| 設定 | 選び方 |
|---|---|
| 保存形式 | MP3／元の形式。「元の形式」は音声を変換せず保存します。 |
| 音質 | MP3 は 320／192／128 kbps から選べます。「元の形式」では音質欄が無効になります。 |
| ファイル名 | 初期値は動画名です。`{uploader} - {title}` にすると「投稿者 - 動画名」になります。`{id}` も使えます。 |

元の音声より高音質にはなりません。同じ名前のファイルがある場合は、番号を付けて保存します。

- **保存した場所を確認する：** 履歴を選択すると下の欄に保存ファイルのパスを表示します。履歴をダブルクリックすると保存フォルダーを開きます。
- **中止する：** 「キャンセル」を押します。通信待ちの間は、中止まで時間がかかることがあります。
- **設定を戻す：** 「詳細設定を開く」から「初期設定にリセット」を押します。履歴と保存済みの音声は残ります。

通常の動画・Shorts・ライブ・YouTube Music の動画 URL に対応しています。
プレイリスト付きの URL でも保存するのは1動画だけです。プレイリスト全体の一括保存には対応していません。
非公開・ログイン必須・地域制限のある動画などは取得できない場合があります。

## 動画を保存する

**Video Download** タブで動画 URL を貼り付け、**Download** を押します。
保存先・保存形式・画質・音声処理・音質・ファイル名を設定でき、保存・リセット・キャンセル・履歴の操作は Music Download と共通です。
設定と履歴はタブごとに独立して保存されます。旧版の設定・履歴は Music Download に引き継がれます。

| 設定 | 選び方 |
|---|---|
| 保存形式 | MP4／MKV。画質とは別に選べます。初期値はMKVです。 |
| 画質 | 最高画質、2160p、1440p、1080p、720p、480p、360p。指定した高さ以下で最良の映像を選びます。該当する映像がない場合はエラーになります。 |
| 音声処理 | 無変換／AAC。初期値は無変換です。 |
| 音質 | AAC は 320／192／128 kbps。「無変換」では音質欄が無効になります。 |

初期設定では「ダウンロード」フォルダーに最高画質で保存します。
動画は初期設定では **MKV形式**、保存形式で「MP4」を選ぶと **MP4形式** で保存し、映像は再圧縮しません。MP4では配信されているMP4映像とM4A音声（または音声付きMP4）から選ぶため、MKVと選べる最高画質が異なる場合があります。保存形式と元の映像コーデックに対応したプレーヤーで再生してください。
画質・音質は元の動画より向上しません。

## 更新・アンインストール

アプリを終了してから、[最新版](https://github.com/sakuya121212/youtube-downloader/releases/latest) をダウンロードしてください。自動更新機能はありません。

- **インストーラー版：** 新しい `-setup.exe` を実行します。
- **ZIP 版：** 新しい ZIP を別フォルダーにすべて展開し、そこから起動します。

同じ Windows ユーザーであれば、更新後も設定と履歴を引き継ぎます。
インストーラー版は Windows の「設定」→「アプリ」から削除できます。ZIP 版はアプリのフォルダーを削除します。
設定・履歴と、アプリとは別の場所に保存した音声は残ります。ZIP のフォルダー内に音声を保存した場合は、先に移動してください。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| ダウンロードできない | 動画をブラウザーで再生できるか確認してください。プレイリストだけの URL ではなく、動画の URL を使ってください。 |
| JavaScript の警告が出る | `No supported JavaScript runtime could be found` は、同梱の実行環境を検出できない警告です。`_internal/node.exe` があるか、セキュリティソフトに隔離されていないか確認してください。 |
| 長い音声の MP3 変換が失敗する | 変換には30分の制限があります。保存形式「元の形式」での保存をお試しください。 |
| 設定・履歴を読み込めない | 表示された保存場所のアクセス権と空き容量を確認してください。データを削除する前にバックアップしてください。 |

解決しない場合は、[問題を報告](https://github.com/sakuya121212/youtube-downloader/issues)してください。
**アプリのバージョン、ZIP／インストーラーの別、警告・エラー全文**を添えると調査しやすくなります。

設定と履歴のバックアップが必要な場合は、アプリを終了してから次のフォルダーをコピーしてください。
音声ファイルは、アプリで指定した保存先にあります。

```text
%LOCALAPPDATA%\YouTubeMusicDownloader
```
